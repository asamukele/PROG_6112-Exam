PROG 6112 – Product Management Application
Project Overview

This project is a Java-based Product Management Application developed as part of the PROG 6112 programming examination.

The application demonstrates object-oriented programming principles, interfaces, product calculations, graphical user interface development, and unit testing.

Features
Product management using Java classes.
Implementation of interfaces.
Product calculation functionality.
Graphical User Interface (GUI).
Product information display.
Unit testing to verify application functionality.
Technologies Used
Java
Java Swing
Object-Oriented Programming (OOP)
JUnit (for unit testing)
NetBeans IDE (if used)
Project Structure
File	Description
MainApp.java	Main application entry point
Product.java	Product class
IProduct.java	Product interface
IProductCalculations.java	Product calculations interface
ProductCalculations.java	Product calculation implementation
PrintProduct.java	Product printing functionality
ProductsAppGUI.java	Graphical user interface
ProductsAppGUI.form	GUI form design
ProductTest.java	Product unit tests
ProductCalculationsTest.java	Calculation unit tests
How to Run the Project
Clone or download this repository.
Open the project files in NetBeans IDE or another Java-compatible IDE.
Ensure that the required Java environment is installed.
Configure the required testing dependencies if necessary.
Run MainApp.java to launch the application.
Testing

The project includes unit tests:

ProductTest.java
ProductCalculationsTest.java

These tests help verify the product functionality and calculation logic.

Learning Objectives

This project demonstrates:

Object-oriented programming concepts.
Java interfaces and implementation.
Encapsulation and class design.
Graphical user interface development.
Software testing and debugging.
